# 🚀 CodeStudio

> **A local-first, AI-powered code editor built for privacy, speed, and seamless development.**

</div>

CodeStudio transforms your browser into a powerful development workspace. By combining Next.js, Monaco, and local LLMs via Ollama, it delivers intelligent code suggestions, interactive AI chat, and agent-style assistance—**without ever sending your source code to external APIs.**

---

## ✨ Key Features

- **💻 Modern Editing Experience:** Powered by Monaco for a robust, VS Code-like environment in your browser.
- **🧠 Local AI Chat:** Seamless prompt enhancement and intelligent conversational assistance routed entirely through **Ollama**.
- **⚡ Smart Code Suggestions:** Real-time playground coding powered by **DeepSeek Coder**.
- **🔒 Complete Privacy:** 100% local model execution ensures your proprietary code never leaves your machine.
- **🛠️ Robust Architecture:** Built on the Next.js App Router with a Prisma-ready backend and agent-style task routing.
- **🔐 Secure Access:** Integrated authentication and personalized dashboard structure.

---

## 🧰 Tech Stack

**Frontend:** Next.js | React | TypeScript | Tailwind CSS 
**Editor:** Monaco Editor  
**AI & Orchestration:** Ollama | LangChain & LangGraph | DeepSeek Coder  
**Backend & Database:** Prisma | NextAuth
